# 拼豆计时管理系统

专为拼豆手工工坊打造的桌台计时管理系统：开台计时、登记支付与套餐、作品储存、每日记录，一个工具管好门店日常。

**纯前端实现，零依赖、零构建，数据只存在本机浏览器里，不上传任何服务器。**

提供两种使用形态：

- 🌐 **网页版**：电脑 / 平板 / 手机浏览器都能用，可安装到桌面（PWA），支持离线
- 📱 **微信小程序版**：`beandou-mp/` 目录，用微信开发者工具导入即可

## 核心功能

### 🕐 桌台看板

- 两种计时模式：**开放计时** / **固定时长**（不少于 5 分钟）
- 一键操作：开台、暂停、继续、加时、换套餐、清空、结束
- **补记起始时间**：忘记顾客到达时间时，可补填精确到分钟的时间点（如 `14:30`），计时立即按该时刻起算并继续实时递增；若填的时间晚于当前时刻，自动按前一天处理
- 开台登记：支付方式（抖音 / 微信 / 支付宝）、套餐、人数、备注
- 套餐包含双人 / 单人 1/2/3 小时与不限时（工作日、周末节假日），抖音另有开业活动价
- 使用中可**换套餐**（只换名头，已用时长与计时不受影响）
- 状态一目了然：空闲（灰）、使用中（绿）、暂停（蓝）、已超时（红）；到期前会提前黄色提醒（默认提前 5 分钟）
- 每张卡片显示**起始时间**与已用时长
- 卡片大小可调：紧凑 / 标准 / 大（紧凑档一屏能放更多桌台，平板推荐）

### 📋 使用记录

- 按日期查看每日记录，可切换前一天 / 今天 / 后一天
- 表格字段：结束时间、桌台、支付/套餐、时长、人数、备注
- 当日汇总：开台数、记录数、客流（人）

### 📦 作品储存

- 记录顾客姓名、联系方式、作品名称、储存日期、预计取走日期、备注
- 自动计算已存天数，超期未取显示「逾期（N 天）」
- 支持标记已取走，按状态筛选

### ⚙️ 系统设置

- 自定义区域与桌台编号（默认 A 区 1-6 桌、B 区 1-4 桌）
- 状态颜色主题自定义
- 超时前提醒（分钟，0 为关闭）+ 超时语音提醒
- 桌台卡片大小、弹窗大小（紧凑 / 标准 / 大）
- 自定义壁纸：可上传多张、随机切换、轮播（关闭 / 每次打开自动换 / 每小时自动换）、遮罩浓度调节
- 数据导出备份（JSON）/ 导入恢复 / 清空今日数据 / 清空全部数据

## 技术栈

- HTML / CSS / 原生 JavaScript（ES2017+），**零依赖、零构建**
- 数据持久化：浏览器 `localStorage`（键名 `pindou_system_v1`）+ JSON 导入导出
- PWA：`manifest.webmanifest` + Service Worker 离线缓存
- 微信小程序：原生小程序框架，自定义 tabBar
- 部署：GitHub Pages 托管，推送到 `main` 分支自动发布，无构建步骤

## 安装与运行

### 网页版（本地预览）

必须通过 HTTP 访问，直接双击打开 `file://` 会导致 Service Worker 和 PWA 不可用：

```bash
# 方式一：Python 3
python -m http.server 8000

# 方式二：Node
npx --yes serve -l 8000 .

# 方式三：使用已配置的脚本
npm run serve
```

然后打开 <http://localhost:8000/index.html>。

> 项目没有任何依赖需要安装，`package.json` 只提供元信息与本地预览脚本。

### 手机 / 平板安装到桌面（PWA）

1. 用浏览器打开网页版地址
2. iOS：Safari → 分享 → 添加到主屏幕
3. Android / 鸿蒙：Chrome 等浏览器 → 菜单 → 添加到主屏幕 / 安装应用

安装后可离线使用，数据保存在设备本地。

### 微信小程序版

用微信开发者工具导入 `beandou-mp/` 目录，填入自己的 AppID 即可运行。

## 基本使用示例

**开台**：在桌台看板点击空闲桌台 → 选支付方式、套餐、人数、计时模式 → 点「开台」。

**忘记计时，事后补记**：点击桌台 → 在「补记起始时间」填顾客实际到达时间（如 `14:30`）→ 点「补记开始」。已用时长立刻按 14:30 起算，并继续按真实时间递增。

**暂停与继续**：点击使用中的桌台 → 「暂停」/「继续计时」。暂停期间不计入时长。

**加时 / 换套餐**：点击使用中的桌台 → 「加时」（不少于 5 分钟，叠加到固定时长）或「换套餐」（只换名头，计时不变）。

**结束**：点击使用中的桌台 → 「结束」→ 确认后生成一条使用记录，桌台恢复空闲。

**备份**：系统设置 → 「导出全部数据(备份)」，换设备时用「导入数据(恢复)」还原。

## 常见问题

**数据存在哪里？会上传吗？**
全部存在本机浏览器 `localStorage`，不上传任何服务器。清除浏览器缓存会丢失数据，请定期在系统设置里导出备份。

**换电脑 / 换手机怎么迁移数据？**
在旧设备「系统设置 → 导出全部数据(备份)」得到 JSON 文件，在新设备「导入数据(恢复)」即可。

**网页版和小程序的数据互通吗？**
不互通。两者各自独立存储，需要迁移时用导出 / 导入。

**改了代码但线上没生效？**
静态资源带版本号缓存（`app.js?v=N`）。修改 `app.js` 或 `styles.css` 后必须同步递增 HTML 里的版本号，否则浏览器和 Service Worker 会继续用旧文件。用户侧可强制刷新或清除站点数据。

**为什么不能双击 HTML 直接打开？**
Service Worker 与 PWA 安装要求安全上下文，`file://` 下不可用。请用上面的本地 HTTP 方式预览。

**切到后台或刷新页面，计时长会不准吗？**
不会。时长是按「起始时间戳与当前时间的差值」实时计算的，不是每秒累加，刷新或切后台后重新打开依然准确。

**补记起始时间能填多久以前的？**
最多 24 小时。填的时间若晚于当前时刻，会自动按前一天计算（适合跨零点营业）。

**怎么改套餐和价格？**
编辑 `app.js` 顶部的 `BASE_PACKAGES` 与 `PACKAGES` 常量，改完记得递增版本号。

**超时没有语音提醒？**
检查系统设置里「超时语音提醒」是否开启，以及浏览器是否允许该站点播放语音（首次需先有一次用户交互）。
