# 拼豆计时管理系统

专为拼豆手工工坊打造的桌台计时管理系统：开台计时、登记支付与套餐、作品储存、每日记录，一个工具管好门店日常。**纯前端实现，无需服务器，数据存在本机浏览器里。**

提供两种使用形态：

- 🌐 **网页版**：电脑、平板、手机浏览器都能用，可安装到桌面（PWA），支持离线
- 📱 **微信小程序版**：`beandou-mp/` 目录，用微信开发者工具导入即可

## 功能总览

### 🕐 桌台看板
- 开放计时 / 固定时长两种模式，开始、暂停、继续、加时、结束一键操作
- 开台登记：**支付方式**（抖音 / 微信 / 支付宝）、**套餐**（含抖音开业活动价）、人数、**备注**
- 使用中可**换套餐**（换支付方式或套餐，计时不变）、随时改备注（结账时）
- 状态颜色一目了然：空闲（灰）、使用中（绿）、暂停（蓝）、即将超时（黄）、已超时（红，闪烁提醒）
- 卡片大小可调：**紧凑 / 标准 / 大**（紧凑档一屏多放桌台，平板推荐）

### 📋 使用记录
- 按日期查看每日开台记录：结束时间、桌台、支付/套餐、备注、时长
- 今日汇总：记录条数、在用桌数

### 📦 作品储存
- 记录顾客姓名、电话、作品与存入 / 取走日期
- 自动计算储存天数，逾期高亮提醒

### ⚙️ 系统设置
- 自定义区域与桌台编号
- 状态颜色主题自定义
- 超时前提醒（分钟）+ 超时语音提醒
- 桌台卡片大小、弹窗大小（紧凑 / 标准 / 大）
- 自定义壁纸 + 每日 / 每小时轮播
- 数据导出备份 / 恢复

## 手机安装到桌面（PWA）

1. 手机或平板浏览器打开上方地址
2. iOS：Safari → 分享 → 添加到主屏幕
3. Android / 鸿蒙：Chrome 等浏览器 → 菜单 → 添加到主屏幕 / 安装应用

安装后离线也能用（Service Worker 缓存），数据保存在设备本地。

## 数据与备份

所有数据保存在**本机浏览器 localStorage**，不上传任何服务器。换设备、清缓存前，先在「系统设置 → 导出备份」导出数据文件，在新设备导入恢复。

## 目录结构

```
├── index.html            # 主界面（默认入口）
├── index-v4.html         # v4 玻璃卡片风格界面
├── app.js                # 全部业务逻辑（各界面共用）
├── styles.css            # 主界面样式
├── styles-v4.css         # v4 叠加样式（需配合 styles.css 使用）
├── manifest.webmanifest  # PWA 清单
├── sw.js                 # Service Worker（离线缓存）
├── icon.jpg              # 应用图标
└── beandou-mp/           # 微信小程序源码
    ├── app.json
    ├── pages/
    │   ├── dashboard/    # 桌台看板
    │   ├── sales/        # 使用记录
    │   ├── storage/      # 作品储存
    │   └── settings/     # 设置
    ├── components/       # modal 弹窗、table-card 桌台卡片组件
    └── utils/            # store 数据层、helpers、alert
```

## 技术栈与部署

- HTML / CSS / 原生 JavaScript，零依赖、零构建
- localStorage 数据持久化 + JSON 导入导出
- PWA：manifest + Service Worker 离线缓存
- **部署**：GitHub Pages 托管，推送到 `main` 分支自动发布，无需任何构建步骤
