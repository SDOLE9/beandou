# 拼豆计时管理系统一款专为拼豆手作工坊打造的桌面与移动端计时管理系统，支持桌台计时、销售记录、储存管理等核心功能。## ✨ 功能特性### 核心功能- **智能计时**：开始、暂停、结账、清空一键操作- **状态指示**：  - 🟢 绿灯 - 正常计时中  - 🔵 蓝灯 - 暂停状态  - 🔴 红灯 - 超时提醒- **桌台管理**：A区、B区分区管理，支持多桌台- **储存管理**：拼豆完成后可记录储存日期- **销售记录**：每日开台、消费、结账完整记录- **数据持久化**：本地 localStorage 存储，数据不丢失### 界面设计- **液态玻璃质感**：模仿 Apple 系统的精致玻璃态 UI- **多版本支持**：  - v1 玻璃态版（[查看演示](https://sdole9.github.io/beandou/index.html)）  - v3 拼豆手作工坊版（[查看演示](https://sdole9.github.io/beandou/index-v3.html)）- **响应式设计**：完美适配桌面和移动设备- **自定义壁纸**：支持上传和切换背景图片### 移动端支持- **PWA 应用**：可添加到手机主屏幕，体验接近原生 App- **离线可用**：Service Worker 缓存，无网络也能使用- **跨平台**：支持 iOS 和 Android 系统## 📱 快速开始### 访问网址- v1 玻璃态版：`https://sdole9.github.io/beandou/index.html`- v3 拼豆手作版：`https://sdole9.github.io/beandou/index-v3.html`### 安装到手机**iPhone (iOS)**1. 在 Safari 打开上方网址2. 点击分享按钮 → "添加到主屏幕"3. 从桌面直接启动**Android**1. 在 Chrome 打开上方网址2. 点击菜单 → "添加到主屏幕" 或 "安装应用"3. 从桌面直接启动## 🗂️ 文件结构```├── index.html              # v1 玻璃态版主页面├── index-v3.html           # v3 拼豆手作版主页面├── styles.css              # v1 样式├── styles-v3.css           # v3 样式├── app.js                  # 核心逻辑├── sw.js                   # Service Worker (离线缓存)├── manifest-v1.webmanifest # v1 PWA 配置├── manifest-v3.webmanifest # v3 PWA 配置└── icon.jpg                # 应用图标```## 🛠️ 技术栈- 纯 HTML / CSS / JavaScript，无需构建- LocalStorage 本地存储- Service Worker 离线缓存- PWA 渐进式 Web 应用## 📝 使用说明1. **开台**：点击桌台的"开始"按钮，开始计时2. **暂停**：休息时点击"暂停"按钮3. **结账**：完成消费后点击"结账"，系统记录销售4. **储存**：拼豆完成需存放时，记录储存日期5. **查看记录**：在销售记录/储存记录页面查看历史数据## 🔄 更新日志### v1.0- 初始版本发布- 支持拼豆计时、销售管理、储存管理- 液态玻璃 UI 设计- 移动端适配- PWA 支持## 📄 开源协议本项目仅供学习和个人使用。---Made with ❤️ for 拼豆手作工坊
